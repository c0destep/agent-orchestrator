# Delegation contract

Every assignment must state goal, exact scope, allowed files, read/write permission, dependencies, acceptance criteria, expected report and stop conditions.

Every result should include evidence with paths, actual checks run, changed files, assumptions, uncertainties and risks. The parent integrates independently. Review/security tasks remain read-only.


## Visibility obligations

The parent alone announces role/model/effort to the user under references/observability.md. Require each child to report actual completion/failure and evidence; a child must not assert that its configured or effective model was used without supported client metadata. Include the exact task label used for user-visible reporting.
